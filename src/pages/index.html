  • Funktioniert offline: Was Sie tun, gilt sofort und wird an den Server übertragen, sobald er erreichbar ist.
  • Neue Nachrichten kommen innerhalb von Sekunden an und erscheinen als Desktop-Benachrichtigung.
  • Regeln, Kategorien, Kennzeichnungen, Signaturen, verzögertes Senden. Große Anhänge werden bei Microsoft 365 über OneDrive geteilt.

  • Freigegebene Postfächer aus Microsoft 365 und Exchange als eigenes Konto.
  • S/MIME: Nachrichten signieren und verschlüsseln, Signaturen prüfen.

    • {{en}}
  • Works offline: whatever you do applies at once and is sent to the server as soon as it can be reached.
  • New mail arrives within seconds and shows up as a desktop notification.
  • Rules, categories, flags, signatures and delayed sending. Large attachments are shared through OneDrive on Microsoft 365.
  • Automatic replies are stored on the server and keep working while your PC is off.
  • Shared mailboxes from Microsoft 365 and Exchange appear as their own account.
  • S/MIME: sign and encrypt messages, check signatures.
  • HTML mail never runs scripts, and remote images (tracking pixels) stay blocked until you allow them.

Ondura sends data only to your own mail and calendar servers, and checks GitHub for updates.{{/}}
